public class PracticeBossAimedSpreadAttackExecutor : PracticeBossAttackExecutorBase//file này tìm vị trí playermovement một lần duy nhất và bắn chùm đạn hình quạt về phía player
{
    [Header("Target Reference")]
    [SerializeField]
    private Transform playerTarget;

    public override PracticeBossAttackPatternType SupportedPatternType =>
        PracticeBossAttackPatternType.AimedSpread;

    protected override void LoadComponents()
    {
        base.LoadComponents();
        ResolvePlayerTarget();
    }

    protected override void OnEnable()
    {
        base.OnEnable();
        ResolvePlayerTarget();
    }

    public void SetPlayerTarget(Transform targetTransform)
    {
        playerTarget = targetTransform;
    }

    public override void ExecuteAttack(
        PracticeBossAttackDefinition attackDefinition,
        Transform firePoint,
        Transform projectileContainer
    )
    {
        if (attackDefinition == null || firePoint == null)
        {
            return;
        }

        ResolvePlayerTarget();

        float centerAngle = CalculateCenterAngleTowardsPlayer(firePoint.position) + attackDefinition.StartingAngleOffset;

        int projectileCount = Mathf.Max(1, attackDefinition.ProjectileCount);

        if (projectileCount == 1)
        {
            Vector2 singleDirection = ConvertAngleToDirection(centerAngle);
            SpawnProjectile(attackDefinition, firePoint, projectileContainer, singleDirection);
            return;
        }

        float totalSpread = Mathf.Clamp(attackDefinition.SpreadAngle, 0f, 360f);
        float startAngle = centerAngle - (totalSpread * 0.5f);
        float angleStep = totalSpread / (projectileCount - 1);

        for (int i = 0; i < projectileCount; i++)
        {
            float currentAngle = startAngle + (angleStep * i);
            Vector2 direction = ConvertAngleToDirection(currentAngle);

            SpawnProjectile(
                attackDefinition,
                firePoint,
                projectileContainer,
                direction
            );
        }
    }

    private float CalculateCenterAngleTowardsPlayer(Vector3 fireOrigin)
    {
        if (playerTarget == null)
        {
            return 0f;
        }

        Vector2 toPlayer = playerTarget.position - fireOrigin;

        if (toPlayer.sqrMagnitude <= 0.0001f)
        {
            return 0f;
        }

        return Mathf.Atan2(toPlayer.y, toPlayer.x) * Mathf.Rad2Deg;
    }

    private void ResolvePlayerTarget()
    {
        if (playerTarget != null)
        {
            return;
        }

        PracticePlayerHealth playerHealth =
            FindFirstObjectByType<PracticePlayerHealth>();

        if (playerHealth != null)
        {
            playerTarget = playerHealth.transform;
        }
    }
}

    private void EvaluatePhaseTransition()
    {
        if (phases == null || phases.Count == 0)
        {
            return;
        }

        float normalizedHealth = GetNormalizedHealth();
        int targetPhaseIndex = currentPhaseIndex;

        for (int i = currentPhaseIndex + 1; i < phases.Count; i++)
        {
            PracticeBossPhaseDefinition candidatePhase = phases[i];

            if (candidatePhase == null)
            {
                continue;
            }

            if (normalizedHealth <= candidatePhase.HealthThreshold)
            {
                targetPhaseIndex = i;
            }
        }

        if (targetPhaseIndex != currentPhaseIndex && targetPhaseIndex >= 0)
        {
            SetPhase(targetPhaseIndex);
        }
    }

        bool hasValidFallback = fallbackAttackDefinition != null && fallbackAttackDefinition.ProjectilePrefab != null;

        if (!hasValidPhase && !hasValidFallback)

    private IEnumerator AttackLoopRoutine()
    {
        if (initialCombatDelay > 0f)
        {
            yield return WaitUntilRunningForSeconds(initialCombatDelay);
        }

        while (CanContinueAttacking())
        {
            yield return WaitUntilGameIsRunning();

            if (!CanContinueAttacking())
            {
                break;
            }

            PracticeBossAttackDefinition selectedAttack = SelectNextAttack();

            if (selectedAttack == null || selectedAttack.ProjectilePrefab == null)
            {
                yield return null;
                continue;
            }

            yield return PerformAttackRoutine(selectedAttack);

            if (!CanContinueAttacking())
            {
                break;
            }

            float runtimeCooldown = CalculateRuntimeCooldown(selectedAttack);
            yield return WaitUntilRunningForSeconds(runtimeCooldown);
        }

        attackInProgress = false;
        attackLoopCoroutine = null;
    }

    private PracticeBossAttackDefinition SelectNextAttack()
    {
        PracticeBossPhaseDefinition activePhase = CurrentPhase;

        if (activePhase == null || !activePhase.HasValidAttacks())
        {
            return fallbackAttackDefinition;
        }

        IReadOnlyList<PracticeBossAttackDefinition> phaseAttacks = activePhase.Attacks;
        List<PracticeBossAttackDefinition> validCandidates = new List<PracticeBossAttackDefinition>();

        for (int i = 0; i < phaseAttacks.Count; i++)
        {
            PracticeBossAttackDefinition attack = phaseAttacks[i];

            if (attack != null && attack.ProjectilePrefab != null)
            {
                validCandidates.Add(attack);
            }
        }

        if (validCandidates.Count == 0)
        {
            return fallbackAttackDefinition;
        }

        if (validCandidates.Count == 1)
        {
            lastSelectedAttack = validCandidates[0];
            return lastSelectedAttack;
        }

        List<PracticeBossAttackDefinition> nonRepeatingCandidates = new List<PracticeBossAttackDefinition>();

        for (int i = 0; i < validCandidates.Count; i++)
        {
            if (validCandidates[i] != lastSelectedAttack)
            {
                nonRepeatingCandidates.Add(validCandidates[i]);
            }
        }

        List<PracticeBossAttackDefinition> poolToPick =
            nonRepeatingCandidates.Count > 0 ? nonRepeatingCandidates : validCandidates;

        int randomIndex = UnityEngine.Random.Range(0, poolToPick.Count);
        lastSelectedAttack = poolToPick[randomIndex];

        return lastSelectedAttack;
    }

    }

        base.OnEnable();

        LoadRigidbody();
        LoadCollider();
        ResetRuntimeState();
    }

    private void Update()
    {
        CheckLifetime();
    }

    private void FixedUpdate()
    {
        MoveProjectile();
    }

    private void OnTriggerEnter2D(
        Collider2D other
    )
    {
        if (!isInitialized ||
            hasHitPlayer ||
            other == null)
        {
            return;
        }

        PracticePlayerHealth playerHealth =
            other.GetComponentInParent<
                PracticePlayerHealth
            >();

        if (playerHealth == null || playerHealth.IsDead)
        {
            return;
        }

        hasHitPlayer = true;

        playerHealth.TakeDamage(damage);

        DestroyProjectile();
    }

    private void LoadRigidbody()
    {
        if (projectileRigidbody != null)
        {
            return;
        }

        projectileRigidbody =
            GetComponent<Rigidbody2D>();
    }

    private void LoadCollider()
    {
        if (projectileCollider != null)
        {
            return;
        }

        projectileCollider =
            GetComponent<Collider2D>();
    }

    public void Initialize(
        Vector2 direction,
        float speed,
        float damageAmount,
        float projectileLifetime
    )
    {
        moveDirection =
            direction.normalized;

        moveSpeed =
            Mathf.Max(0f, speed);

        damage =
            Mathf.Max(0f, damageAmount);

        lifetime =
            Mathf.Max(
                0.1f,
                projectileLifetime
            );

        despawnTime =
            Time.time + lifetime;

        hasHitPlayer = false;
        isInitialized = true;

        if (projectileCollider != null)
        {
            projectileCollider.enabled = true;
        }
    }

    private void MoveProjectile()
    {
        if (!isInitialized ||
            projectileRigidbody == null)
        {
            return;
        }

        Vector2 displacement =
            moveDirection *
            moveSpeed *
            Time.fixedDeltaTime;

        Vector2 nextPosition =
            projectileRigidbody.position +
            displacement;

        projectileRigidbody.MovePosition(
            nextPosition
        );
    }

    private void CheckLifetime()
    {
        if (!isInitialized)
        {
            return;
        }

        if (Time.time < despawnTime)
        {
            return;
        }

        DestroyProjectile();
    }

    private void DestroyProjectile()
    {
        isInitialized = false;

        if (projectileCollider != null)
        {
            projectileCollider.enabled = false;
        }

        PracticeObjectPoolManager.DespawnOrDestroy(gameObject);
    }

        if (projectileCollider != null)

        }
    }

    {
        if (projectileCollider != null)

        }
    }

    private Vector2 GenerateSpawnPosition()
    {
        float gamePlayPlaneZ = 0f;
        float distanceFromCameraToPlane = Mathf.Abs(gamePlayPlaneZ - mainCamera.transform.position.z);

        Vector3 bottomLeft = mainCamera.ViewportToWorldPoint(new Vector3(0f, 0f, distanceFromCameraToPlane));
        Vector3 topRight = mainCamera.ViewportToWorldPoint(new Vector3(1f, 1f, distanceFromCameraToPlane));

        float cameraleft = bottomLeft.x;
        float cameraRight = topRight.x;
        float cameraBottom = bottomLeft.y;
        float cameraTop = topRight.y;

        SpawnEdge selectedEdge = (SpawnEdge)Random.Range(0, 4);
        switch (selectedEdge)
        {
            case SpawnEdge.Top:
            {
                float randomX = Random.Range(cameraleft, cameraRight);
                return new Vector2(randomX, cameraTop + spawnPadding);
            }
            case SpawnEdge.Bottom:
            {
                float randomX = Random.Range(cameraleft, cameraRight);
                return new Vector2(randomX, cameraBottom - spawnPadding);
            }
            case SpawnEdge.Left:
            {
                float randomY = Random.Range(cameraBottom, cameraTop);
                return new Vector2(cameraleft - spawnPadding, randomY);
            }
            case SpawnEdge.Right:
            {
                float randomY = Random.Range(cameraBottom, cameraTop);
                return new Vector2(cameraRight + spawnPadding, randomY);
            }
            default:
                return Vector2.zero;
        }
    }
